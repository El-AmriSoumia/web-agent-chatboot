## 🎓 Glossaire

- **Recording** : Première exécution qui enregistre les actions
- **Replay** : Exécutions suivantes qui réutilisent le script généré
- **Workflow** : Ensemble d'actions enregistrées et réutilisables
- **Script Generator** : Module qui génère le code Python
- **Workflow Manager** : Module qui gère les workflows (recherche, création, exécution)
- **Normalisation** : Transformation du prompt en format standardisé
- **Paramètres** : Valeurs détectées automatiquement (email, password, phone)
